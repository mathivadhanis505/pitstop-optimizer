Pipeline Architecture & Data Quality

ETL

• Extraction: OpenF1 REST API with FastF1 fallback; cached locally in .fastf1_cache/.

• Cleaning: Driver code normalization, compound mapping, and pit duration sanitization.

• Database Load: Idempotent bulk UPSERT into races, results, stints, pit_stops, and lap_telemetry.

• Materialized View: Refreshes mv_driver_championship post-ingestion.
